# AURA — ювелирный сайт на данных 1С (каталог-витрина)

Сайт ювелирной сети: **дизайн AURA** в корне репозитория, в него встроены
**реальные данные из 1С** (выгрузка обновляется ежедневно) через лёгкий сервер.
Корень репозитория — и локальная витрина, и то, что публикуется на GitHub Pages:
один контур, один источник правды.

## Состав

| Папка | Что это |
|---|---|
| `server/` | Бэкенд: генератор витрины (`catalog_build.py`), API + статика (`api.py`), заказы на самовывоз, слой кабинета и бонусов (`loyalty.py`) |
| `assets/` | Дизайн-слой (`tokens.css` → `aura.css` → `theme-sun.css`), интерфейс (`ui.js`, `hero.js`, `fx.js`, `icons.js`) и живая интеграция (`live.js`) |
| `analysis/` | Документация этапов: анализ 1С-данных, схема интеграции, мастер-план, отчёт по готовности (ЭТАП 7) |
| `_qa/` | Регрессионные проверки: контраст, функциональные тесты, ссылки, Lighthouse, схема, кабинет (в git не хранится) |

## Запуск (ПК с хранилищем 1С — BizHub)

1. `server/build_catalog.bat` — собрать витрину каталога из данных 1С (после каждой выгрузки с флешки);
2. `server/start_api.bat` — поднять сервер → http://127.0.0.1:8138

Проверка:
- `/index.html` — главная (хиты/новинки/категории на реальных товарах);
- `/catalog.html` — каталог (+ `?cat=Серьги`, поиск `?q=серьги`);
- `/product.html?id=2` — реальная карточка товара (разметка `Product` собирается из 1С);
- `/salon.html?city=Егорьевск` — «Свой салон рядом»;
- `/cart.html` — корзина и заказ на самовывоз;
- `/account.html` — кабинет: вход по коду, заказы, бонусы (`POST /api/auth/start`, `POST /api/auth/verify`, `GET /api/account`);
- `/orders.html` — заказы с сайта (код доступа по умолчанию `aura2026`, задаётся env `AURA_ORDERS_TOKEN`).

## Что важно знать
- Рабочий контур один — корень репозитория; `mockups/` — локальный архив дизайна (в git не хранится).
- В 1С **нет фотографий товаров** — витрина показывает честную заглушку «Фото скоро»,
  а не снимок другого украшения; наполнение фото — отдельный шаг.
- Цена на витрине — «последняя продажа» (с пометкой на карточке). Доизвлечение регистра
  «ЦеныНоменклатуры» из полного файла 1С — следующий технический шаг.
- Внутренние данные 1С (телефоны клиентов, обороты) в этот репозиторий и на сайт не попадают.

Подробности: `server/README.md` и `analysis/ЭТАП-6.1_каталог-детальная-схема.md`.
