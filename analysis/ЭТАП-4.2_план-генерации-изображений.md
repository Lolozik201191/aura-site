## 2. Единый стиль генераций (чтобы выглядели «одной съёмкой»)

**Промпт-якорь (вставлять в каждый промпт):**
```
editorial jewelry product photography, real 585 gold jewelry, warm ivory seamless
background (#F6F3EC), soft diffused studio light with gentle champagne-gold rim,
macro detail, natural metal texture, subtle soft shadows, premium boutique catalog
style, photorealistic, 8k detail
```
**Отрицательный промпт (единый):**
`text, watermark, logo, signature, cartoon, illustration, 3d render, low quality, extra fingers`

**Правила:**
- Фон/свет выдерживать «Тёплое сияние»: айвори #F6F3EC, акценты шампань #C4A06A, тёмный бархат для премиум-кадров.
- Один «рецепт света» на серию → кадры складываются в карусели/ленты без визуального шума.
- Соотношения: карточка 1:1, «на руке/модели» 4:5, баннеры/герой 16:9, обложки салона 3:2.
- Для согласованности серии держать одинаковые seed/промпт-обвязку и генерить по 2–4 варианта на кадр, отбирать лучший.

## 3. Маппинг: блок → изображения → страница (приоритеты)

### P0 — «пилот» (1 кадр-тест, потом ~10 кадров на 3 страницы)
1. Тест канала: 1 изображение «кольцо 585 с бриллиантом, макро на айвори» → проверить качество/цену/лимиты.
2. Карточка товара «Аврора» (product.html): 5 кадров галереи — макро; вид сбоку/сверху; «на руке» (4:5); в подарочной коробке AURA; с паспортом/биркой.
3. Каталог «Кольца» (catalog.html): 6 фото карточек (кольцо с бриллиантом, обручальные, помолвочное, «на каждый день», с печаткой, комплект) — заменить SVG в `PICS`.
4. Главная: 3 кадра ленты «Хиты AURA» + кадр промо «Свадьба» (пара колец на фоне).

### P1 — основной набор (ещё ~20–25 кадров)
- Wedding: обручальная пара на айвори; помолвочное в руках/коробочке; руки с кольцами (lifestyle); украшения невесты; свадебная пара (боке).
- Салон: интерьер салона (тёплый свет, витрины с золотом); зона примерки; крупный план витрины; команда/консультант (аккуратно, без лиц при необходимости).
- Главная: hero-кадр сезонной кампании (если заменять существующий), «Новинки» фото, «Свой салон рядом» lifestyle.
- Серьги/колье/браслеты для будущих категорий каталога.

### P2 — расширение (по мере добавления категорий/страниц городов)
- Остальные SKU каталога (серьги, колье, подвески, цепи, браслеты), фото «на модели», упаковка/подарочные наборы, сертификаты.

**Номенклатура файлов:** `mockups/assets/pics/{sku}-{view}.jpg`
(например `avrora-macro.jpg`, `avrora-hand.jpg`, `avrora-box.jpg`, `rings-hits-1.jpg`, `salon-interior.jpg`).
**Альбомы:** `assets/pics/products/`, `assets/pics/lifestyle/`, `assets/pics/salon/`.

## 4. Каналы генерации (решение — после пилота)

### Вариант A — SiliconFlow Qwen-Image (ключ уже есть)
- Endpoint: `POST https://api.siliconflow.com/v1/images/generations`, `model: "Qwen/Qwen-Image"`, `response_format: "b64_json"`.
- Плюс: ничего настраивать не нужно; единый ключ с vision.
- Минус/условие: нужен баланс на международной площадке (cloud.siliconflow.com → «费用/充值»); точную цену и квоту проверить первым тестовым кадром.

### Вариант B — OpenRouter + встроенный генератор DSH (рекомендуется для продакшена генераций)
- Добавить ключ `sk-or-…` (OpenRouter) в настройки DSH (поле image-generation/openrouter) → генератор приложения оживёт (Gemini `google/gemini-3.1-flash-lite-image`, ~центовые доли за кадр).
- Плюс: встроенный UI, сохранение в workspace (`dsh-image-gen/`), управление из приложения.
- Минус: нужен ваш ключ (регистрация openrouter.ai, бесплатный стартовый кредит).

### Вариант C — реальные фото au-ra.ru / сток (только для макетов)
- Быстро и бесплатно; для финального продукта использовать реальные фото товаров AU-RA + лицензионный сток.

> Рекомендация: **пилот на A (бесплатно/дёшево) → при масштабировании выбрать B** для скорости, либо C, если в продакшен пойдут реальные фото.

- Оптимизация: JPEG q≈80 / WebP, ширина 900–1200px (карточки) — макеты останутся лёгкими.

## 7. Ограничения честности
- Сгенерированные изображения — **не реальные товары AU-RA**: при показе заказчику маркировать набор как «фото-заглушки/концепт»; для боевого сайта использовать фото реальных изделий (с au-ra.ru/съёмка) либо явно оформить сток-лицензии.
- Итоговые цены/размеры в подписях не должны конфликтовать с картинкой (генерация не знает фактических параметров изделия).
