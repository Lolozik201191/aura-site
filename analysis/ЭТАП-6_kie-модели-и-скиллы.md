## 3. Предлагаемый медиа-конвейер проекта

1. **Товарные фото** — сейчас: `gpt-image-2 i2i` (10 кредитов). Дальше дешевле: `nano-banana-edit` (4) + `recraft/remove-background` (1) = 5 кредитов за идеальный белый фон.
2. **Баннеры** — `seedream/4.5` или `nano-banana` (4–6 кредитов) на фон + **текст только через CSS** (без выжигания текста в картинке: русский язык модели искажают).
3. **Hero и большие баннеры** — апскейл `topaz/image-upscale` (10 кредитов) до 2K.
4. **Внешнее ревью и тексты** — `gpt-5-2` (vision + копирайт): 11 экранов стоят ~2 кредита.
5. **Видео** (по желанию заказчика) — `seedance-2-mini` 5 сек ≈ 102 кредита, собирается из фото товара.

**Бюджетные ориентиры** (баланс сейчас: ~790 кредитов):
- полный цикл фото 25 позиций через дешёвый путь: ~125 кредитов ($0.63);
- 6 баннеров: ~40 кредитов;
- апскейл 4 hero: 40 кредитов;
- ревью всех экранов: ~5 кредитов;
- одно видео 5 сек: ~102 кредита.
Итого «достойный публикации» медиа-пакет: **~310 кредитов (~$1.55)**, с видео — ~410 (~$2).

## 4. Каких скиллов/инструментов не хватает для качественного дизайна

### Уже есть
| Скилл/инструмент | Для чего |
|---|---|
| `ui-ux-pro-max` (design_recommend / design_review / design_search) | дизайн-система, палитры, типографика, UX-правила |
| `vision-skills` (локальный vision-тулкит) | описание экранов, кроп, палитра, пиксельный диff — **но есть лимиты** |
| `generate-anything` (KIE) | генерация изображений/видео/звука |
| Ollama Qwen2.5-VL локально | бесплатные проверки читаемости и композиции |
| Свои скрипты `_qa/` | контраст WCAG, функциональные тесты, аудит ссылок, скриншоты через CDP |

### Чего не хватает (и как закрыть)
| Пробел | Почему важно | Как закрыть |
|---|---|---|
| **Дизайн-токены в одном месте** | сейчас 3 слоя CSS конфликтуют, правки дорожают | рефакторинг в `tokens.css` + семантические переменные |
| **Lighthouse / производительность** | без замера нельзя гарантировать «достойно публикации» | добавить прогон `npx lighthouse` в CI + оптимизация шрифтов и картинок |
| **Schema.org / структурированные данные** | расширенные сниппеты, доверие поисковиков | внедрить Product, Offer, AggregateRating, LocalBusiness, BreadcrumbList |
| **Полный a11y-прогон** (не только контраст) | фокус, aria, скринридер | axe-core через CDP + ручной чеклист, фикс мега-меню и модалок |
| **UX-райтинг как отдельный этап** | тексты решают доверие; ревью показало «размытые формулировки» | проход по всем текстам с `gpt-5-2` (дёшево) + ваш бренд-словарь |
| **Визуальная регрессия** | правки ломают вёрстку незаметно | эталонные скриншоты + `vision_pixel_diff` в пайплайне |
| **CI-публикация** | сейчас пуши руками, ключи в temp-репозитории | GitHub Actions: сборка, проверки, деплой на Pages/домен |
| **Аналитика и цели** | без неё не измерить эффект дизайна | Яндекс.Метрика + события на ключевые CTA |
| **Бренд-ассеты в векторе** | логотип сейчас PNG (растровый, мылится) | запросить SVG у заказчика или обвести растр через `vision_trace` |

## 5. Что делаю следующим шагом (предложение оркестратора)

1. **Прогон полного ревью через `gpt-5-2`** по 11 экранам → сводный отчёт с приоритетами (готово, ~2 кредита).
2. **Закрыть топ-3 из ревью**: выбор размера в карточке, строка категорий под логотипом, окна акций.
3. **Рефакторинг токенов** и удаление конфликтующих слоёв CSS.
4. **Schema.org + Lighthouse** и починка найденного.
5. **Дешёвый путь для фото** (`nano-banana-edit` + `remove-background`) для оставшихся позиций и для новых товаров.
6. **CI-публикация** на домен заказчика.
