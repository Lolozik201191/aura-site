## 2. Каталог и навигация

Общая модель у всех: «каталог → тип изделия → металл/проба/вставка», горизонтальные подкатегории чипами, карусели. Различия:
- Sunlight: огромное мегаменю с брендами и «отделами» (часы/очки/сумки — не только ювелирка); адреса категорий строятся через URL-фильтры (brand, proba, stone).
- Соколов: в мегаменю есть и неювелирные разделы (Часы, Косметика); категория золота дробится по пробе (585) и металлу.
- 585: максимально широкие SEO-подборки (по пробе 375/585/750, по типам, «клевер», «итальянские», «ручной работы» и т.п.) — система «сайт-витрина для поисковиков».
- MIUZ: каталог структурирован по коллекциям и камню, а не только по типу; фирменные артикулы отражают дизайн (R01-SOL35 = кольцо коллекции Solo). Плюс осознанный раздел «свадьба» и «галерея камней».

## 13. Фишки лидеров (Sunlight, MIUZ) — чего нет у «средних»

### Sunlight
- Персональные цены для вошедших («Войдите, чтобы купить по этой цене») + механика ХИТ-цены.
- Встроенные рассрочки Сплит/Долями прямо в карточке с наглядным расчётом платежей.
- Видео в карточке, крупнейшая база отзывов с фото/видео (2000+ на товар).
- Сервисы «одним экраном»: ломбард, скупка, обмен — часть одного сайта.
- Чат в мессенджере + «Вопросы и ответы».

### MIUZ
- Бренд-легенда «завод со 100-летней историей» как ядро доверия.
- «Галерея камней»: продажа сертифицированных бриллиантов с фильтрами по характеристикам (4C) + «бесплатная оправа».
- УИН и лазерная гравировка номера бриллианта (гос. прослеживаемость) — сильный аргумент доверия.
- Бессрочная гарантия, персонализация (гравировка), сервисная карта.
- Омниканальность: «Забрать в салоне», «Запланировать встречу», 300 салонов, виджет обратного звонка «перезвоним через 28 секунд».
- Сдержанный графит+золото дизайн, «дорогой» редакционный стиль.
- Коллекции как способ навигации (Solo 1920, Flaming Ice…), а не только типы изделий.

### Уникальное у 585 (но дешёвое по стилю)
- Прозрачный расчёт цены «Больше о цене» (цена без скидок → скидка).
- ИИ-сводка отзывов «что говорят покупатели».
- Примерка нескольких изделий при самовывозе.

## 14. Чего нет ни у кого — возможные уникальные решения для вас

1. **Интерактивная виртуальная примерка в браузере** — примерить кольцо/серьги/браслет на фотографии своей руки или через камеру (AR). У всех четырёх сайтов её нет (приложения Соколова — частично). Самый сильный «вау»-аргумент.
2. **ИИ-консьерж-подборщик** — чат, который подбирает украшения по случаю (свадьба/годовщина/подарок), бюджету и предпочтениям, а не только отвечает на вопросы. У 585 есть ИИ только для сводки отзывов; полноценного «цифрового стилиста» нет ни у кого.
3. **«Паспорт украшения»** — у каждого изделия онлайн-карточка с историей: происхождение металла и камня, сертификаты, УИН, уход — красивая и честная подача (у MIUZ только зачатки через УИН).
4. **Умная «свадебная корзина»** — комплектование парных колец с учётом размеров и бюджета, чек-лист подготовки к свадьбе (у всех есть только раздел «свадьба», инструмента нет).

Рекомендация: для премиального позиционирования взять №1 или №3 как «фишку сайта», №2 — как сервис поддержки. №4 — если делаете акцент на свадьбу.

## 15. Вывод для вашего проекта

- **За образец структуры и удобства** взять Sunlight (навигация, каталог, фильтры, карточка).
- **За образец стиля** взять MIUZ (графит + золото, воздух, серифные акценты) — он почти совпадает с вашей утверждённой гаммой (#1A1A1A + #D4AF37/#F7E7CE), просто у вас глубже тёмный фон.

- **Избегать**: синих кнопок Соколова и «оранжевых скидочных лихорадок» 585 — они противоречат люксовому стилю.
- **Ваша ниша-отличие** — тёмный премиум-фон (никто из четырёх не строит сайт на тёмной теме) + выбранная фишка из раздела 14.
